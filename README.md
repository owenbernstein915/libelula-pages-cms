# Libélula Bakery + Kitchen

Editable Vite/React source reconstructed from the September 4, 2026 Netlify deployment.

## Local development

```bash
npm install
npm run dev
```

## Netlify

- Build command: `npm run build`
- Publish directory: `dist`
- Production branch: `main`

## Pages CMS

The root `.pages.yml` exposes website copy, images, links, hours, reviews, and the full menu. Editors use the hosted Pages CMS app; each save creates a Git commit, which triggers Netlify continuous deployment.
